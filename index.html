음성 인식은 “글자”로 변환된 결과를 비교합니다. 인식기가 억양 자체를 평가하지는 않으니, 점수보다 서울말 음성을 듣고 따라 하는 것이 핵심입니다.

서울말 말하기 기본

  • 문장 끝을 크게 올리거나 내리지 말고, 의문문은 끝 음절만 가볍게 올립니다. (뭐 해?↗)
  • 높낮이를 과하게 주기보다 문장 전체를 비교적 평평하게, 강세는 약하게 말합니다.
  • “-요” 어미를 또렷이 붙이면 훨씬 자연스러운 서울말이 됩니다.

경상도 → 서울말에서 자주 틀리는 것

  • ㅓ와 ㅡ 구분: 음식(으-ㅁ식), 은행, 그림 — “엄식·언행”으로 소리 나지 않게.
  • ㅅ과 ㅆ 구분: 쌀 ≠ 살, 쏘다 ≠ 소다.
  • 어미: -노/-나/-데이 → -어/-야, -입니꺼 → -입니까.

전라도 → 서울말

  • -랑께/-당께/-잉 → -라니까/-다니까 (또는 생략)
  • 어휘: 거시기 → 그것/그거, 겁나·허벌나게 → 엄청, 시방 → 지금

충청도 → 서울말

  • -유/-슈 → -요/-어요, -는겨 → -는 거야
  • 말이 느리게 들리니, 문장 끝을 조금 짧고 분명하게 맺기.

연습 방법 (추천)

  • 하루 5문장: 듣기 → 따라 말하기 → 점수 확인 → 틀린 글자만 다시.
  • 휴대폰으로 내 목소리를 녹음해 서울 아나운서 음성과 번갈아 들어 보세요.
